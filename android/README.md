# Android 0.3.2 微信兼容试用版

支持 Android 11+；新增的 **微信兼容模式需要 Android 13+**。它针对“服务已连接、其他应用能触发，但微信事件无法识别 mj”的情况提供另一条识别路径。**本版已完成编译和逻辑检查，尚未完成真机或模拟器运行复测，不能据此认定微信问题已解决。**

## 下载与覆盖更新

手机浏览器 [直接下载 APK](https://github.com/vakasu11/mj-spiderman-desktop-effect/releases/download/android-v0.3.2/mj-spiderman-android-0.3.2.apk)，或打开 [发布页](https://github.com/vakasu11/mj-spiderman-desktop-effect/releases/tag/android-v0.3.2)，在 Assets 选择 `mj-spiderman-android-0.3.2.apk`。`Source code` 是源码。

包名与签名沿用旧版，versionCode=5，可覆盖更新；请勿先卸载，以免清除设置。应用无内置自动更新。

## 微信兼容模式：更新后需要手动开启

1. 安装后打开 **mj-spiderman**，完成首次说明，确认“特效已开启”。
2. 开启 **“微信兼容模式”**，阅读并同意单独说明。此开关默认关闭；升级不会自动替你同意。
3. 点 **“无障碍服务设置”**，手动关闭再重新开启同名服务，让系统重新建立输入连接。
4. 回应用确认实际连接；再进入微信聊天输入框，点一下让键盘弹出，稍等约一秒，让连接初始化。
5. 用英文输入法输入 `mj`、连续 `mjmj`，再用中文输入法尝试。支持大小写和全角 `ｍｊ`；若组合字母只在键盘候选栏中，请先提交英文字母。无需发送消息。
6. 首次进入已有草稿不会自动重播。删除后重新输入也可以测试；输入法将多组字母合并为一次变化时只播放一次。

这条路径使用 Android 的无障碍输入连接，不需要切换或安装另一套键盘。系统或微信仍可能不提供连接、周边文字或未提交的拼音内容。Android 11/12 保留原有控件识别，不提供此模式。

若仍失败，回应用点 **“复制诊断信息”**，提供“微信兼容模式、最近微信连接、微信连接读取、连接匹配、实际连接”及复现步骤。计数不含输入文字。离开微信后“当前未聚焦输入框”可能正常，需结合“最近微信连接”判断。

## 普通输入与试听

开启系统里的同名无障碍服务后，回应用确认实际连接，先试听两套动画，再在应用测试框及其他应用测试 `mj` / `mjmj`。中文与英文输入法都可尝试，全角 `ｍｊ` 也支持；输入法未公开的候选内容无法保证识别。

**“输入法兼容”** 默认开启，补查聚焦的非密码输入控件；与单独的“微信兼容模式”是两个开关。微信兼容模式开启时，微信改走输入连接识别，其他应用沿用原路径。应用测试框使用自身文字监听。

暂停、锁屏或熄屏时不识别新输入。动画层不接收触摸。主按钮暂停不会关闭系统授权；“停止并关闭无障碍服务”经确认后完全停用服务。

## 服务与后台状态

0.3.0 曾将系统绑定列表误当作授权开关。0.3.1 起分别读取设置勾选、系统绑定和实际连接；读取受限显示未知。诊断包含本应用退出原因、微信事件及只读查询计数。升级退出记录不代表异常。

服务未连接时，在系统设置手动关闭再开启。若真实开关被系统关闭，可在“后台运行与服务帮助”检查电池和后台限制。应用不会自行强制授权，无法保证后台永不回收；未完成首次说明时保持空闲。

## 声音与勿扰

音效预加载到 SoundPool，使用媒体音量。应用内音量键调整媒体音量；检查声音开关、媒体音量、蓝牙 / 耳机及勿扰设置。应用不修改勿扰或强制提高音量，系统仍决定是否允许播放媒体。

## 输入能力、权限与本地数据

无障碍具有读取其他应用文字的能力，需要用户手动授权。0.3.2 在服务声明中新增 `flagInputMethodEditor` 输入连接能力：系统接口本身支持读取和编辑，本应用仅调用 `getSurroundingText` 只读查询，**不调用输入、删除、按键或发送接口**。没有新增 `uses-permission`，但这是一项新增的无障碍能力，应用内设有单独说明和同意开关。

只有同意并开启微信兼容模式后，才查询包名为 `com.tencent.mm` 的普通文本输入框；跳过密码、数字及无法确认类型的输入框，选中文字时暂停匹配。请求光标前后各最多 64 个字符的周边上下文（系统可能同时返回选区），仅临时处理；匹配状态保留最多 128 个 m / j / 其他分类与光标信息，不保留原文。读取前后和播放前校验输入上下文，切换输入框后丢弃过期结果。关闭此模式后停止该路径的读取。

普通控件路径的临时事件队列有数量限制，去重只保留内存指纹和光标元数据。不记录或上传完整输入，不声明 INTERNET、存储、麦克风、通知或普通悬浮窗权限。保存开关、服务提示、异常类型和不含文字的计数，不保存异常消息、私人录屏或输入历史。

接口说明：[Android 无障碍输入连接能力](https://developer.android.com/reference/android/accessibilityservice/AccessibilityServiceInfo#FLAG_INPUT_METHOD_EDITOR)、[只读周边文字查询](https://developer.android.com/reference/android/accessibilityservice/InputMethod.AccessibilityInputConnection#getSurroundingText(int,int,int))。

## 构建与验证范围

使用 JDK 21、Android SDK Platform 36、Build Tools 36.0.0 与 Python 3，无 Gradle 和第三方 Android 库。

```powershell
python android/build_apk.py --jdk "JDK目录" --platform "SDK/platforms/android-36" --tools "SDK/build-tools/36.0.0" --out "dist/android"
```

215 项文字匹配、14 项系统设置解析、29 项周边文字识别检查通过；APK 编译、v3 签名、对齐及 248 个原始媒体文件逐字节校验通过。覆盖安装使用同一签名。音效在 APK 中不压缩；开发私钥位于被 Git 忽略的 `work/android-development.keystore`，不得提交或分发，后续覆盖更新需要保留它。

上述检查不包含手机端运行证明。微信输入连接、中文组合输入及 Android 17 等实际系统兼容性仍需设备复测。
