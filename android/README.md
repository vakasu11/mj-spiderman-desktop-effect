# Android 0.3.0 修复试用版

Android 11+，面向 iQOO 15 / Android 16 制作。针对连续输入漏触发、服务开关状态与音效提示进行修复。205 项文字匹配检查、编译、签名、对齐及 248 个原作媒体文件校验通过。**新版尚未完成真机或模拟器运行复测，不能保证全部应用、输入法或后台管理策略均兼容。**

## 下载与覆盖更新

手机浏览器 [直接下载 APK](https://github.com/vakasu11/mj-spiderman-desktop-effect/releases/download/android-v0.3.0/mj-spiderman-android-0.3.0.apk)，或打开 [发布页](https://github.com/vakasu11/mj-spiderman-desktop-effect/releases/tag/android-v0.3.0)，在 Assets 选择 `mj-spiderman-android-0.3.0.apk`。`Source code` 是源码。

本版包名与签名不变，versionCode 提升至 3，可在 0.1.0 / 0.2.0 上尝试覆盖安装。请勿先卸载，避免清除开关设置。应用无内置自动更新。

## 首次设置与复测

1. 安装后先打开 **mj-spiderman**，完成首次说明。
2. 点 **“无障碍服务设置”**，由你手动开启系统里的同名服务。升级后若已开启但未连接，可手动关闭再开启。
3. 回应用确认 **“特效已开启”** 且提示服务已实际连接。只有系统已授权但尚未连接时会单独提示。
4. 保持 **“输入法兼容”** 开启，先试听两套动画。
5. 在本应用测试框切到英文，分别测试 `mj`、连续 `mjmj`，以及删除后重新输入。测试框使用原生文字监听，避免依赖无障碍回传。
6. 再切到微信等应用，在支持的输入框测试。输入法把多个 mj 合成一次变化时只播放一次，避免声音叠加。

## 服务开启后自动关闭怎么办

旧版在首次说明未确认时会主动关闭刚开启的服务。0.3.0 改为保持用户打开的系统开关、等待在应用内确认，确认前不读取输入。

新版同步处理系统连接、断开和应用暂停状态。**暂停特效** 不等于关闭系统服务；**停止并关闭无障碍服务** 需要再次确认后才执行。打开应用界面和关闭界面均不会主动停用服务。

若仍自动关闭，点 **“后台运行与服务帮助” → “打开应用信息”**，检查应用电池与后台运行限制，具体菜单随手机系统版本变化。系统开关由 Android 管理，应用不能替你强制开启，也无法保证系统永不回收。

再次发生时，点击 **“复制诊断信息”** 并提供复现步骤。诊断包含应用版本、服务开关与实际连接状态、识别开关、最近服务状态和异常类型，不含输入文字。

## 输入法兼容

默认开启，会在事件识别之外补查当前聚焦的非密码输入框，识别新出现的 mj。改善候选词整段替换、重复事件和部分漏事件，但可能增加耗电；不需要时可关闭此开关。锁屏、熄屏、暂停或关闭服务时不会识别输入。

只读取系统提供的可编辑控件，仍不保证自绘输入框、受保护控件或输入法未公开的候选内容可用。密码控件跳过。不保存跨应用的完整文本，只在内存保留文字指纹和光标元数据来去重；进入已有 mj 的输入框不会立刻重播。

## 声音和勿扰

音效改为预加载短音效，并使用媒体音量，避免每次触发都在主线程同步准备播放器。应用内按音量键调整媒体音量；页面会提示媒体音量为零或勿扰开启。

**不强行提高音量，不修改勿扰模式，不绕过系统的声音策略。** 勿扰期间是否允许媒体播放取决于手机设置。没有声音时检查媒体音量、声音开关、蓝牙 / 耳机输出及勿扰设置。

## 权限与本地数据

无障碍服务能读取其他应用输入控件中的文字，需要你阅读应用说明并手动授权。未完成说明时服务保持空闲，不处理输入。

不联网、不记录或上传输入文字，不声明 INTERNET、存储、麦克风、通知或普通悬浮窗权限。保存的只有开关、服务状态提示和异常类型；不保存异常消息、完整输入或录屏。音效直接读取 APK 里的原版 WAV。没有新增前台服务或自动开启权限的功能。

## 构建

使用 JDK 21、Android SDK Platform 36、Build Tools 36.0.0 与 Python 3，无 Gradle 和第三方 Android 库。

```powershell
python android/build_apk.py --jdk "JDK目录" --platform "SDK/platforms/android-36" --tools "SDK/build-tools/36.0.0" --out "dist/android"
```

脚本会运行文字匹配检查、打包原作素材并签名校验。音效在 APK 中不压缩，以便异步加载。开发签名密钥位于被 Git 忽略的 `work/android-development.keystore`，不得提交或分发；后续覆盖更新需要保留同一私钥。
