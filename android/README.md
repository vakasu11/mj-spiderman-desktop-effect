# Android 0.3.1 修复试用版

Android 11+，面向 iQOO 15 / Android 16 制作。针对连续输入漏触发、服务开关状态与音效提示进行修复。215 项文字匹配检查、14 项系统开关解析检查、编译、签名、对齐及 248 个原作媒体文件校验通过。**新版尚未完成真机或模拟器运行复测，不能保证全部应用、输入法或后台管理策略均兼容。**

## 下载与覆盖更新

手机浏览器 [直接下载 APK](https://github.com/vakasu11/mj-spiderman-desktop-effect/releases/download/android-v0.3.1/mj-spiderman-android-0.3.1.apk)，或打开 [发布页](https://github.com/vakasu11/mj-spiderman-desktop-effect/releases/tag/android-v0.3.1)，在 Assets 选择 `mj-spiderman-android-0.3.1.apk`。`Source code` 是源码。

本版包名与签名不变，versionCode 提升至 4，可在 0.1.0 / 0.2.0 上尝试覆盖安装。请勿先卸载，避免清除开关设置。应用无内置自动更新。

## 首次设置与复测

1. 安装后先打开 **mj-spiderman**，完成首次说明。
2. 点 **“无障碍服务设置”**，由你手动开启系统里的同名服务。升级后若已开启但未连接，可手动关闭再开启。
3. 回应用确认 **“特效已开启”** 且提示服务已实际连接。只有系统已授权但尚未连接时会单独提示。
4. 保持 **“输入法兼容”** 开启，先试听两套动画。
5. 在本应用测试框用中文和英文输入法分别测试 `mj`、连续 `mjmj`，以及删除后重新输入；也支持全角 `ｍｊ`。测试框使用原生文字监听，避免依赖无障碍回传。
6. 再切到微信等应用，在支持的输入框测试。中文拼音只有在输入法将组合字母公开到输入框时才能识别；如果只显示在键盘候选栏中，请先提交英文字母。输入法把多个 mj 合成一次变化时只播放一次，避免声音叠加。

## 0.3.1 针对微信断开与诊断误报的修正

跨应用控件查询移到独立线程，回调只短暂复制事件并放入有数量限制的队列，避免控件响应慢时阻塞服务主线程。应用内测试框仍用自己的原生文字监听。

**0.3.0 的“系统开关”字段实际上使用了系统的已绑定服务列表，断开后可能误报成开关关闭。** 0.3.1 改为分别报告：系统设置是否勾选本服务、系统绑定列表是否存在服务、本进程是否实际连接。设置读取不允许时显示“未知”，不当作关闭。此修正依据 [Android 16 的系统实现](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android16-release/services/accessibility/java/com/android/server/accessibility/AccessibilityManagerService.java) 与 [系统设置字段说明](https://developer.android.com/reference/android/provider/Settings.Secure#ENABLED_ACCESSIBILITY_SERVICES)。

新版诊断增加本应用最近的进程退出原因（如 ANR、异常、升级等）、微信事件 / 可读控件 / 匹配数量及最长控件查询耗时。升级造成的退出记录不代表故障；未记录 Java 异常也不排除 ANR 或系统终止。这些诊断不含输入文字。

## 服务开启后自动关闭怎么办

旧版在首次说明未确认时会主动关闭刚开启的服务。0.3.1 改为保持用户打开的系统开关、等待在应用内确认，确认前不读取输入。

新版同步处理系统连接、断开和应用暂停状态。**暂停特效** 不等于关闭系统服务；**停止并关闭无障碍服务** 需要再次确认后才执行。打开应用界面和关闭界面均不会主动停用服务。

若仍自动关闭，点 **“后台运行与服务帮助” → “打开应用信息”**，检查应用电池与后台运行限制，具体菜单随手机系统版本变化。系统开关由 Android 管理，应用不能替你强制开启，也无法保证系统永不回收。

再次发生时，点击 **“复制诊断信息”** 并提供复现步骤。诊断包含应用版本、设置勾选与绑定 / 实际连接状态、识别开关、最近服务状态、异常类型、本应用退出原因和微信输入检查计数，不含输入文字或其他应用的已授权列表。

## 输入法兼容

默认开启，会在事件识别之外补查当前聚焦的非密码输入框，识别新出现的 mj。改善候选词整段替换、重复事件和部分漏事件，但可能增加耗电；不需要时可关闭此开关。锁屏、熄屏、暂停或关闭服务时不会识别输入。

只读取系统提供的可编辑控件，仍不保证自绘输入框、受保护控件或输入法未公开的候选内容可用。密码控件跳过。不保存或上传跨应用的完整文本，事件数据仅在有界队列处理期间临时使用，去重状态只保留内存中的指纹和光标元数据；进入已有 mj 的输入框不会立刻重播。

## 声音和勿扰

音效改为预加载短音效，并使用媒体音量，避免每次触发都在主线程同步准备播放器。应用内按音量键调整媒体音量；页面会提示媒体音量为零或勿扰开启。

**不强行提高音量，不修改勿扰模式，不绕过系统的声音策略。** 勿扰期间是否允许媒体播放取决于手机设置。没有声音时检查媒体音量、声音开关、蓝牙 / 耳机输出及勿扰设置。

## 权限与本地数据

无障碍服务能读取其他应用输入控件中的文字，需要你阅读应用说明并手动授权。未完成说明时服务保持空闲，不处理输入。

不联网、不记录或上传输入文字，不声明 INTERNET、存储、麦克风、通知或普通悬浮窗权限。保存开关、服务状态提示、异常类型与不含文字的输入检查计数；进程退出原因从 Android 的本应用历史读取。不保存异常消息、完整输入或录屏。音效直接读取 APK 里的原版 WAV。没有新增前台服务或自动开启权限的功能。

## 构建

使用 JDK 21、Android SDK Platform 36、Build Tools 36.0.0 与 Python 3，无 Gradle 和第三方 Android 库。

```powershell
python android/build_apk.py --jdk "JDK目录" --platform "SDK/platforms/android-36" --tools "SDK/build-tools/36.0.0" --out "dist/android"
```

脚本会运行文字匹配检查、打包原作素材并签名校验。音效在 APK 中不压缩，以便异步加载。开发签名密钥位于被 Git 忽略的 `work/android-development.keystore`，不得提交或分发；后续覆盖更新需要保留同一私钥。
